# Task Tracker Contracts

Общий модуль с контрактами взаимодействия между микросервисами Task Tracker.

Содержит DTO, события и модели сообщений, используемые при межсервисном взаимодействии.

## Возможности

* Общие Response
* Kafka Events
* Kafka RPC Request
* Kafka RPC Response

## Технологии

* Java
* Maven
* Apache Kafka

## Использование

Модуль подключается как зависимость к микросервисам, которым необходимы общие контракты.
